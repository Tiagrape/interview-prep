5.1 编译原理小抄（2020 本单位穿插 2 题，容易失分）

  • 编译 5 个阶段：词法分析 → 语法分析 → 语义分析与中间代码生成 → 优化 → 目标代码生成
  • 词法分析：正则表达式 ↔︎ 有限自动机（NFA 可确定化为 DFA）
  • 语法分析：上下文无关文法（CFG）；自上而下（递归下降、LL(1)）vs 自下而上（LR、算符优先）
  • 推导：最左推导 / 最右推导（规范推导）、句型 / 句子 / 短语 / 直接短语 / 句柄
  • 中间代码：四元式、三地址码、逆波兰式（后缀表达式）
  • 符号表：名字、类型、作用域
  • 目标：至少能认出概念、在选项里挑对，不求推导

5.2 SQL 手写模板（必练）

-- 1) 两表连接（2020 原题难度：很简单）
SELECT a.id, a.name, b.score
FROM student a
JOIN score b ON a.id = b.student_id
WHERE b.score > 60;

-- 2) 分组聚合 + 排序
SELECT dept, COUNT(*) AS cnt, AVG(salary) AS avg_sal
FROM emp
GROUP BY dept
HAVING COUNT(*) > 5
ORDER BY avg_sal DESC;

-- 3) 子查询（高于本部门平均薪资的人）
SELECT name FROM emp e
WHERE salary > (SELECT AVG(salary) FROM emp WHERE dept = e.dept);

六、编程题：这次要练”手写”

项目 要求

八、给你的 3 条判断（说人话）

  1. 这单位是”正牌”金融基础设施 IT：新三板 / 北交所的技术子公司，工作地北京金融街，2020 年笔经提到”据说基本能解决京户”。值得认真准备。
